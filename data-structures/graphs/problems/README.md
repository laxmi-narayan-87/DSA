# Graph Practice

## Foundations

- Represent an edge list as an adjacency list and adjacency matrix.
- Count connected components in an undirected graph.
- Determine whether a path exists between two vertices.
- Find the number of islands in a grid using BFS or DFS.

## Traversal and structure

- Clone a graph.
- Detect a cycle in directed and undirected graphs.
- Check whether a graph is bipartite.
- Find connected components and strongly connected components.
- Topologically sort courses/tasks and detect dependency cycles.

## Shortest paths and spanning trees

- Shortest path in an unweighted graph using BFS.
- Dijkstra with non-negative edge weights.
- Bellman-Ford with negative-edge handling.
- Minimum spanning tree using Kruskal or Prim.
- Disjoint-set union for dynamic component merging.

## Advanced

- Bridges and articulation points.
- Strongly connected components (Kosaraju or Tarjan).
- Multi-source BFS and 0–1 BFS.
- Network flow and bipartite matching.

Always test disconnected graphs, isolated vertices, self-loops, duplicate edges, and cycles. State whether complexity is expressed in vertices V and edges E.
