# Array Practice

Use these topics as a roadmap and store actual submissions in `solutions/platforms/<platform>/` or `solutions/languages/<language>/`.

## Foundations

- Find the minimum and maximum.
- Linear search and binary search.
- Reverse an array in place.
- Remove duplicates from a sorted array.
- Merge two sorted arrays.

## Two pointers and in-place updates

- Two Sum in a sorted array.
- Move zeroes to the end.
- Rotate an array by k positions.
- Sort an array containing only 0, 1, and 2.
- Container With Most Water.

## Prefix sums and sliding windows

- Range-sum queries with prefix sums.
- Maximum subarray sum (Kadane's algorithm).
- Longest subarray satisfying a given constraint.
- Minimum-size subarray with sum at least a target.
- Count subarrays with a target sum.

## Search and advanced patterns

- Search in a rotated sorted array.
- Find first/last occurrence of a value.
- Find a peak element.
- Merge overlapping intervals.
- Product of array except self.

For every problem, record the invariant, time complexity, auxiliary space, and whether the solution mutates the input.
