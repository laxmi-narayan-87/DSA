# Tree Practice

## Fundamentals

- Implement preorder, inorder, postorder, and level-order traversal.
- Find maximum depth, minimum depth, and number of nodes.
- Invert a binary tree and check whether two trees are identical.
- Check whether a tree is height-balanced or symmetric.

## Binary search trees

- Search, insert, and delete a key.
- Validate a BST using lower and upper bounds.
- Find kth smallest/largest values.
- Find the lowest common ancestor in a BST and in a general binary tree.

## Intermediate and advanced

- Build a tree from traversal arrays.
- Serialize and deserialize a binary tree.
- Find maximum path sum and diameter.
- Perform vertical order, boundary, and zigzag traversal.
- Understand AVL and red-black rotations, B-trees, and their invariants.

For each solution, clarify whether height counts nodes or edges and how duplicate keys are handled.
