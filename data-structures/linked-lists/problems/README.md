# Linked List Practice

Use these patterns to choose practice problems in the platform archive. Keep submitted solutions under `solutions/platforms/<platform>/` and language archives under `solutions/languages/<language>/`.

## Beginner

- Reverse a linked list iteratively and recursively.
- Find the middle node.
- Merge two sorted linked lists.
- Remove a node by value and remove duplicates from a sorted list.

## Intermediate

- Detect a cycle and return its entry node.
- Find the intersection of two lists.
- Remove the Nth node from the end.
- Reorder a list using a midpoint and reversal.
- Add two numbers represented by linked lists.

## Advanced

- Reverse nodes in groups of size k.
- Copy a list with random pointers.
- Sort a linked list in O(n log n) time.
- Flatten a multilevel doubly linked list.

## Review checklist

For every problem, state the invariant, handle empty and one-node inputs, and analyze time and auxiliary space. Prefer O(1) extra space when the problem permits safe in-place pointer updates.
